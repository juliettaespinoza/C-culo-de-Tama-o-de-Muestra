Cálculo de tamaño de muestra

El cálculo de tamaño de muestra es un aspecto fundamental de un diseño de estudios, al permitir aproximar la cantidad mínima de participantes requeridos para probar la hipótesis planteada, así como validar la factibilidad del mismo.

Importancia

La finalidad de emplear una técnica de muestreo estadístico en un trabajo de investigación, radica en emplear la inferencia estadística para extrapolar los resultados a una población objetivo.

Si bien un mayor tamaño y mayor representativas de muestra, implican menor variabilidad del resultado y mayor precisión; el muestreo permite estimar el tamaño mínimo requerido para que se pueda garantizar que la hipótesis sea probada al término del estudio.

Conceptos Básicos para realizar un cálculo de Tamaño de Muestra

  • Nivel de significancia (\(\alpha\)): Probabilidad de rechazar la hipótesis nula cuando es verdadera. Por convención, se considera que un valor \(p<0.05\), es estadísticamente significativo.

  • Poder de estudio( \(1- \beta\)): Capacidad del estudio para detectar un efecto real (evitar falsos positivos). Por convención, se busca el 80% o más.

  • Tamaño del Efecto Esperado: Estimación de que tan fuerte o grande será el efecto o cambio que se espera encontrar del tratamiento.

  • Variabilidad de la población: Cuantifica que tan dispersos o variados son los datos en realidad.

Objetivos de aprendizaje

Después de finalizar esta práctica desarrollada debería ser capaz de:

  • Calcular de forma adecuada el tamaño de muestra

  • Comprender los escenarios más comunes de cálculo de tamaño de muestra

Escenario 1: Muestra para estimar incrementos de una media en una misma población

Este escenario tiene la finalidad de evaluar si la media de un grupo independiente cambia respecto a un valor referencial, usualmente obtenido de la literatura.

Resolución

  1. Cálculo del efecto del diseño

    \[ d = |u1 - u2|/sd \]

  2. Cálculo del tamaño de muestra

    Uso de la función pwr.t.test

  3. Cálculo del poder de estudio

    Uso de la función pwr.t.test

  4. Cálculo del efecto con los valores ya encontrados

    Uso de la función pwr.t.test

Caso practico

Un programa nutricional busca aumentar los niveles de hemoglobina de un valor base de \(20 \text{ mg/dL}\) hasta \(30 \text{ mg/dL}\) (diferencia de \(10\)), con una desviación estándar de \(10\text{ mg/dL}\)

Supuestos:

  • 2 colas
  • Ho: m=m0 <- Hipótesis nula, donde m es la media
  • Ha: m!=m0, m=20 <- Hipótesis nula
  • diff=10 (o ma=30) <- Diferencia o Hipótesis nula
  • sd=10 <- Desviación estándar
  • p=0.05 <- Nivel de significancia
  • power=0.80 <- Poder de estudio

Para resolverlo, empleamos los pasos ya mencionados:

  3. Cálculo del poder de estudio:

    Uso de la función pwr.p.test

    Uso de la función pwr.p.test

Escenario 7: Muestra para estimar la media entre dos o más poblaciones independientes

Este escenario tiene la finalidad de calcular el tamaño de muestra e inferir el efecto para un ANOVA de una vía cuando se introducen directamente los vectores de medias y la varianza intragrupo observada.

Resolución

  1. Cálculo del tamaño de muestra:

    Uso de la función power.anova.test especificando n=NULL

  2. Cálculo del poder de estudio:

    Uso de la función power.anova.test especificando power=NULL

  3. Cálculo del efecto de diseño: \[\text{Efecto} = \frac{\max(\text{medias}) - \min(\text{medias})}{\text{SD común}}\]

Caso práctico

Se desea evaluar la diferencia entre \(3\) poblaciones independientes con medias esperadas de \(550\), \(598\) y \(610\), y una varianza dentro de los grupos de \(6400\).

Supuestos

  • Grupos = 3 (\(k=3\))

  • Vector de medias: c(550, 598, 610)

  • Varianza intra-grupo (within.var) = 6400

  • p=0.05 <- Nivel de significancia

  • power=0.80 <- Poder de estudio

Para resolverlo, empleamos los pasos ya mencionados:

grupos <- c(550,598,610)
